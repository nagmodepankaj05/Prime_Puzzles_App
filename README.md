## 📱 About Prime Puzzles

**Prime Puzzles** is an Android quiz application designed to make learning and testing knowledge more interactive.

The app provides
<ul>
  <li> category-based multiple-choice quizzes  </li>
  <li> progressive difficulty levels  </li>
  <li> daily challenge  </li>
  <li> score tracking  </li>
  <li> lifelines  </li>
  <li> settings  </li>
  <li> local progress storage (Offline Mode)  </li>
</ul>

## 🏆 Daily Challenge

Prime Puzzles includes a daily challenge mode.

- A challenge is generated for the current day.
- The challenge can be played once per day.
- After completion, it is marked as completed for that day.
- A new challenge becomes available on the next day.
- The feature is designed to work without an online question service.

## 🎮 Quiz Experience

During a quiz, users can:

- Read the current question
- Select one of four answers
- Track question progress
- Watch the remaining time
- Earn points for correct answers
- Use available lifelines
- Skip a question
- Continue to the next question
- Receive visual feedback for correct and incorrect answers

## 💾 Offline Architecture

The quiz questions are stored locally in:

```text
QuestionBank.java
```

User progress and application settings are stored locally using:

```text
SharedPreferences
```

This allows the core quiz functionality to operate without requiring a remote database or API.
